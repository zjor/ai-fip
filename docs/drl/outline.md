# Deep reinforcement learning outline

##### Постановка задачи
Найти стратегию (Policy) для навигации в Environment (World). Есть пространство состояний  (S); множество действий (A).
- $a = \pi(s)$ - функция, которая говорит, какое действие `a` совершить в состоянии `s`.
- оптимальная стратегия $\pi^*=argmax_\pi{E[R|\pi]}$ - максимизирует суммарное вознаграждение в среднем
##### Glossary
- $V(S)-function$ - ценность пребывания в данном состоянии, учитывает будущее ожидаемое вознаграждение; $V_\pi(S)$ - функция ценности состояния с учетом стратегии $\pi$
- $Q(S, A)$ - качество принятия решения `a` в состоянии `s`; $Q_\pi(S, A)$ - функция качества при стратегии $\pi$; из Q-функции можно посчитать V-функцию, и наоборот
##### Model bases vs Model free reinforcement learning
Моделью мира является известная Марковская цепь (MDP), множество состояния, вероятности переходов и вознаграждения (S, A, R, T) - (states, actions, rewards, transitions)
- **Model-based** - зная MDP, задача сводится к поиску оптимальной стратегии, простому планированию действий, алгоритмы: *value iteration*, *policy iteration*
- **Model-free** - агент должен найти оптимальную стратегию, не зная функций переходов и вознаграждения заранее, для этого он должен взаимодействовать со средой; алгоритмы: Q-learning
