# Физика проекта — конспект

Освежающий конспект терминов и физики, на которых построены решения по мотору ([критерии](../hardware/hardware.md#motor-selection-criteria), [кандидаты](../hardware/motor-candidates.md)).

## 1. Момент силы (torque), Н·м
Сила × плечо рычага. Интуиция: 1 Н — вес ~100 г, значит 1 Н·м = 100 г на метровой линейке = **1 кг на плече 10 см**. Крышка банки ≈ 1–2 Н·м. Наши моторы (0.5–1.7 Н·м) = удержать 200–700 г на конце 25-см стержня горизонтально.

## 2. Момент гравитации на маятнике
τ = m·g·l·sin θ (m·l — сумма масса×расстояние всех деталей). При θ=0 момент нулевой, растёт с наклоном. Масса **на оси вращения** (l≈0) не даёт ничего — поэтому батарея на оси. Спасаемый угол — где момент мотора сравнивается с гравитацией.

## 3. K_t — константа момента
τ = K_t·I: ньютон-метры на ампер. Мотор = преобразователь ампер в момент.

## 4. K_v и связь с K_t
Крутящийся мотор — сам генератор: противо-ЭДС растёт со скоростью, при равенстве с напряжением батареи разгон кончается: ω_max = K_v·V. Та же физика с двух сторон: K_t = 9.55/K_v (K_v в rpm/V). **Быстрый = слабый на ампер, сильный = медленный.**

## 5. Закон Ома и предел тока
I_max = V/R. Гимбал-моторы: R велико → 14.8 В продавит лишь ~3 А → момент ограничен **напряжением**. mj5208: R крошечное → ограничивает **драйвер** (20–100 А). Суть переворота решения 2026-08-10.

## 6. 3S / 4S
LiPo-ячейки по 3.7 В последовательно: 3S = 11.1 В, 4S = 14.8 В.

## 7. K_m = K_t/√R — инвариант статора
Перемотка в n раз больше витков: K_t ×n, R ×n² → K_t/√R не меняется. Это качество железа/магнитов: момент на ватт тепла. Без лимита тока моторы сравнивают по K_m.

## 8. Тепло: P = I²R
Ток, не ставший движением, греет медь квадратично. Балансирование = stall duty (момент на нулевой скорости, без обдува) → отсюда разница peak / continuous момента.

## 9. Момент инерции и угловой момент
I_w ∝ m·R² (масса на ободе эффективнее). H = I_w·ω — запас вращения. III закон Ньютона: разгон колеса по часовой = пинок маятнику против часовой. Ёмкость H_max = I_w·ω_max; при насыщении (колесо на максимуме оборотов) управление кончилось.

## 10. Swing-up
Подъём из виса: E = 2·m·g·l. «Разогнал—тормознул»: при торможении H передаётся маятнику. Сила пинка ограничена K_t·I_max независимо от оборотов; обороты дают ДЛИТЕЛЬНОСТЬ пинка (больше H). Мало одного пинка — качаем в резонанс несколькими тактами. С mj5208 (~4900 rpm @ 4S) запас H огромный.

## 11. FOC — векторное управление
Драйвер по энкодеру держит поле статора под 90° к ротору (как толкать качели в такт) → плавный точный момент на любой скорости, включая ноль. Отсюда «командовал 0.2 Н·м — получил 0.2 Н·м», критично для sim-to-real.

## 12. Cogging
Залипание ротора на зубцах статора — ступенчатый паразитный момент около нуля скорости. У гимбалов мал; у mj5208 — открытый вопрос (у moteus есть компенсация — проверить перед заказом).
