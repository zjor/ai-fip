# moteus host controller (planned)

Control loop for the 2026 build: Raspberry Pi + pi3hat (CAN-FD, IMU) commanding a moteus driver with an mjbots mj5208 motor. Python, LQR first, then the ONNX policy from `software/rl/models/`.

See [docs/hardware/hardware.md → Driver: moteus](../../../docs/hardware/hardware.md) and [project/roadmap.md](../../../project/roadmap.md) Phase 3. Current work is tracked in [project/tasks.md](../../../project/tasks.md).
